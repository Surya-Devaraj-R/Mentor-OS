# My C# Lessons

This is my own personal space to learn to code, step by step, in very simple English.

Each lesson is its own small project. To run any lesson:

```
cd Learning/LessonX_Name
dotnet run
```

This folder is kept separate from the main MentorOS app on purpose, so nothing here can ever break the real app.
